# Recursos conferidos

Links que já passaram pelo `npm run links` e estão em algum episódio ou na página de materiais. Ao gerar uma temporada nova, comece por aqui: é mais seguro reaproveitar um link conferido do que escrever um de memória.

Antes de usar um link que não está nesta lista, abra a página. Para vídeos do YouTube, confira o título pelo oEmbed (é o que o `npm run links` faz):

```bash
curl "https://www.youtube.com/oembed?format=json&url=https://www.youtube.com/watch?v=ID_DO_VIDEO"
```

Se o vídeo não existe, a resposta é um erro 400 ou 404.
