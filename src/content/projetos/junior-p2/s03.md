Agora o cálculo. Cada contrato gera um **holerite**: bruto, descontos, líquido e quanto custa para a empresa. E cada tipo de contrato tem uma conta diferente, o trabalho ideal para um switch com **record patterns**.

## Desmontando o record no case

Um padrão de tipo, `case Clt clt`, dá o objeto; um **record pattern** dá os componentes direto:

```java
case Clt(String nome, long salario, int dependentes) -> { ... }
```

Dentro do caso, `nome`, `salario` e `dependentes` já são variáveis prontas. Quando o caso precisa de várias linhas, use um bloco e termine com `yield`, que devolve o valor do switch.

## Percentual em centavos

Calcular 9% de um valor em centavos é `valor * 9 / 100`, mas a divisão inteira **corta** a parte decimal. Somar 50 antes de dividir transforma o corte em arredondamento:

```java executar
long valor = 333_333;                          // R$ 3.333,33
System.out.println(valor * 9 / 100);           // corta
System.out.println((valor * 9 + 50) / 100);    // arredonda
```

```saida
29999
30000
```

> [!MATEMATICA]
> 9% de R$ 3.333,33 é R$ 299,9997. Cortando, viram 29.999 centavos; arredondando, 30.000, que é R$ 300,00. Somar 50 funciona porque 50 é metade de 100: o que passava de meio centavo sobe para o próximo. A Marina inteira: previdência de 9% de R$ 4.500,00 = R$ 405,00; base = 4.500 - 405 - 200 de um dependente = R$ 3.895,00; o que passa da isenção é 3.895 - 3.000 = R$ 895,00; 15% disso dá R$ 134,25. Descontos: 405 + 134,25 = R$ 539,25, e o líquido fica em R$ 3.960,75.
