A etapa 3 tem um bug de regra de negócio: a Sofia recebeu R$ 6.500,00 sem ter emitido a nota fiscal, exatamente o problema que o financeiro contou no pedido. Nesta etapa, o cálculo passa a poder dizer "não pague".

## Um resultado que pode ser dois

`calcular` não pode mais devolver sempre um `Holerite`. Crie outra hierarquia selada:

```java
sealed interface Pagamento permits Holerite, Bloqueado {}
record Bloqueado(String nome, String motivo) implements Pagamento {}
```

e faça `Holerite` implementar `Pagamento`. Quem recebe um `Pagamento` é obrigado, pelo compilador, a tratar os dois casos.

## Guardas com when

Um `case` pode ter uma condição extra, a **guarda**, depois de `when`:

```java
case Pj(String nome, long valor, boolean notaEmitida) when !notaEmitida -> new Bloqueado(nome, "falta a nota fiscal do mês");
case Pj(String nome, long valor, boolean notaEmitida) -> ...   // os PJ com nota
```

A ordem importa: o caso com guarda vem **antes** do caso geral. Ao contrário, o caso geral pegaria todos os PJ, e o compilador reclamaria que o de baixo nunca roda.

## O que construir

1. As interfaces e records de `Pagamento`, e o `calcular` devolvendo `Pagamento`.
2. Um método `Folha.imprimir(Contrato[])` que imprime uma tabela alinhada com `printf`, com cabeçalho, e a linha `bloqueado: falta a nota fiscal do mês` para quem não pode receber.

```text
Nome            Contrato         Bruto    Descontos       Líquido
Marina Costa    CLT        R$ 4.500,00    R$ 539,25   R$ 3.960,75
Sofia Lemos     bloqueado: falta a nota fiscal do mês
```

> [!ANTES]
> O switch com padrões e os record patterns ficaram prontos no Java 21; antes, eram prévia. No Java 22 chegaram as **variáveis sem nome**: quando um componente não é usado, como o `valor` do PJ bloqueado, dá para escrever `case Pj(var nome, _, var notaEmitida)`. Este projeto escreve os tipos por extenso para compilar também no Java 21, o da prova 1Z0-830.

> [!PENSE]
> `Bloqueado` podia ser um `Holerite` com tudo zerado e um campo `observacao`. Por que um tipo separado é mais seguro na hora de somar o total da folha?
