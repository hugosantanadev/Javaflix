Duas regras do banco ainda faltam: a tarifa a partir do quarto saque e o limite diário. E o código já começa a se repetir: a conta que transforma centavos em `R$ 1234,05` vai aparecer em quatro lugares. Esta etapa resolve as duas coisas.

## Lembrar o que já aconteceu

As regras novas dependem do passado: quantos saques já foram feitos e quanto já saiu hoje. Isso vira duas variáveis declaradas **antes** do laço, para não voltarem a zero a cada volta: `int saques` e `int sacadoHoje`.

A tarifa de um saque depende só de quantos saques já aconteceram, e o operador ternário resolve numa linha: `long tarifa = saques >= 3 ? 250 : 0;`.

## Números com nome

`250`, `3` e `1000` soltos no meio do código obrigam quem lê a adivinhar o que significam, e mudar a tarifa vira uma caça a todos os `250`. Dê nome a eles com constantes, declaradas na classe, fora do `main`:

```java
static final long TARIFA = 250;          // R$ 2,50, em centavos
static final int SAQUES_GRATIS = 3;
static final int LIMITE_DIARIO = 1_000;  // em reais
```

`final` impede que o valor mude, e o nome em maiúsculas com `_` é a convenção para constantes em Java.

## Um método para formatar

Um **método** é um trecho de código com nome, que você chama de vários lugares. A temporada [Métodos](/?t=junior-t2) cobre todos os detalhes; para este projeto, basta o formato:

```java
static String formatar(long centavos) {   // recebe um long, devolve uma String
    // ... a conta que você já escreveu na etapa 2 ...

}
```

O método fica dentro da classe e fora do `main`, e se chama assim: `System.out.println("Saldo: " + formatar(saldo));`.

## O que construir

1. Crie as três constantes e as variáveis `saques` e `sacadoHoje`.
2. No saque, a partir do quarto, cobre `TARIFA` junto com o valor e mostre `Tarifa cobrada: R$ 2,50` depois das notas.
3. Se o saque fizer o total do dia passar de R$ 1000, recuse com `Passa do limite diário. Hoje ainda dá para sacar R$ 200.` (com o valor que ainda resta).
4. O saldo precisa cobrir saque **mais** tarifa.
5. Crie o método `formatar` e use em todas as mensagens com dinheiro. O depósito passa a mostrar `Depósito feito. Saldo: R$ 1484,05`.

> [!PENSE]
> Um saque de R$ 300 quando o limite já está em R$ 900 e o saldo está em R$ 50 é recusado pelas duas regras. Qual mensagem a pessoa deve ver? A ordem dos `else if` decide.

> [!BOAPRATICA]
> Quando o mesmo trecho aparece pela terceira vez, extraia um método. Se a regra de formatação mudar, por exemplo para mostrar o ponto do milhar, você muda num lugar só e não esquece nenhum.
