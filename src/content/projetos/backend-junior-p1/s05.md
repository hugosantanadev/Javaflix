Com o quadro do time cheio, ninguém quer receber 300 tarefas numa resposta só. A última etapa traz filtro e paginação na listagem, e prepara o servidor para atender várias pessoas ao mesmo tempo.

## Parâmetros na URL

`GET /tarefas?concluida=false&pagina=2&tamanho=10` traz os parâmetros depois do `?`, separados por `&`. Pegue a parte crua com `getRawQuery()`, quebre em pares e decodifique cada lado com `URLDecoder.decode(texto, StandardCharsets.UTF_8)`: na URL, um espaço chega como `+` ou `%20`.

Valores padrão: `pagina` 1 e `tamanho` 10. Recuse com `400` uma página menor que 1, um tamanho fora de 1 a 50 e um `concluida` que não seja `true` ou `false`.

> [!MATEMATICA]
> A página `p` com `t` itens por página começa no item `(p - 1) × t`, contando do zero: a página 2 de tamanho 2 pula 2 itens e começa no terceiro. O número de páginas é o teto de `total ÷ t`, que em inteiros se escreve `(total + t - 1) / t`: com 3 tarefas e tamanho 2, (3 + 1) / 2 = 2 páginas. O teto de 50 por página não é detalhe: sem ele, `tamanho=1000000` obriga a API a montar uma resposta gigante, outro jeito de derrubá-la.

A resposta passa a ser um objeto com os itens e os dados da página:

```text
{"itens":[...],"pagina":2,"tamanho":2,"total":3}
```

## Várias requisições ao mesmo tempo

Sem configuração, o `HttpServer` atende uma requisição por vez, na thread que o iniciou. Com `servidor.setExecutor(Executors.newVirtualThreadPerTaskExecutor())`, cada requisição ganha uma **thread virtual**, do Java 21: são tão leves que dá para ter milhares, e uma requisição lenta não trava as outras. É aqui que o `ConcurrentHashMap` e o `AtomicLong` da etapa 2 mostram para que serviam.

2. Os `400` dos parâmetros inválidos.
3. O executor de threads virtuais.
4. O teste final, com os 10 cenários que passam pela API inteira, terminando em `10 de 10 conferidos`.
5. Um README com cada rota e um exemplo de `curl`. Commit: `feat: filtro, paginação e threads virtuais`.

> [!PENSE]
> Uma requisição lista as tarefas enquanto outra apaga uma delas. A listagem pode mostrar a tarefa apagada? Pode dar erro? O `ConcurrentHashMap` garante que nada quebra, mas não que a lista seja uma "foto" de um instante só. Para a maioria das APIs isso basta; um banco de dados, com transações, dá garantias mais fortes, como você vai ver no próximo projeto.

> [!BOAPRATICA]
> Compare o tamanho do seu código com o que esta API seria em Spring Boot: roteamento, conversão de JSON, validação e erros viram anotações. Guarde este projeto. Quando um `@RestController` se comportar de um jeito estranho, você vai saber o que ele está fazendo por baixo.
