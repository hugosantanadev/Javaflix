Agora a API ganha o seu recurso principal: tarefas, que você cria, lista e busca. É a metade do CRUD, e com ela aparece o primeiro problema de quem não usa framework: converter JSON.

## O recurso e onde ele mora

Uma tarefa é um record, `Tarefa(long id, String titulo, boolean concluida)`, com um método `json()` que a escreve como texto. As tarefas ficam num `Map<Long, Tarefa>`, e o id vem de um contador. Use `ConcurrentHashMap` e `AtomicLong` desde já: na etapa 5 a API vai atender várias requisições ao mesmo tempo, e um `HashMap` comum ou um `long` com `++` perdem dados quando duas threads mexem juntas, como na temporada [Código thread-safe](/?t=senior-t2).

## Ler JSON sem biblioteca

O Jackson, que o Spring usa, não está no JDK. Para não transformar o projeto num parser, use o leitor pequeno abaixo, que entende objetos planos com textos, inteiros, booleanos e `null`. Leia o código com calma: é uma versão minúscula do que o Jackson faz no [Por baixo dos panos](/assistir/backend-junior-t2-e03) da temporada.

```java compila
import java.util.LinkedHashMap;
import java.util.Map;

/** Um leitor de JSON pequeno, só para objetos planos com textos, números inteiros, booleanos e null. */
final class Json {
    private final String s;
    private int i;

    private Json(String s) {
        this.s = s;
    }

    static Map<String, Object> lerObjeto(String texto) {
        Json leitor = new Json(texto);
        Map<String, Object> objeto = leitor.objeto();
        leitor.espacos();
        if (leitor.i != texto.length()) throw leitor.erro("texto depois do fim do objeto");
        return objeto;
    }

    private Map<String, Object> objeto() {
        espacos();
        esperar('{');
        Map<String, Object> mapa = new LinkedHashMap<>();
        espacos();
        if (olhar() == '}') {
            i++;
            return mapa;
        }
        while (true) {
            espacos();
            String chave = texto();
            espacos();
            esperar(':');
            espacos();
            mapa.put(chave, valor());
            espacos();
            char c = proximo();
            if (c == '}') return mapa;
            if (c != ',') throw erro("esperava , ou }");
        }
    }

    private Object valor() {
        char c = olhar();
        if (c == '"') return texto();
        if (s.startsWith("true", i)) {
            i += 4;
            return true;
        }
        if (s.startsWith("false", i)) {
            i += 5;
            return false;
        }
        if (s.startsWith("null", i)) {
            i += 4;
            return null;
        }
        if (c == '-' || Character.isDigit(c)) {
            int inicio = i++;
            while (i < s.length() && Character.isDigit(s.charAt(i))) i++;
            return Long.parseLong(s.substring(inicio, i));
        }
        throw erro("valor não suportado");
    }

    private String texto() {
        esperar('"');
        StringBuilder sb = new StringBuilder();
        while (true) {
            char c = proximo();
            if (c == '"') return sb.toString();
            if (c < 0x20) throw erro("caractere de controle dentro do texto");
            if (c != '\\') {
                sb.append(c);
                continue;
            }
            char escape = proximo();
            switch (escape) {
                case '"', '\\', '/' -> sb.append(escape);
                case 'n' -> sb.append('\n');
                case 't' -> sb.append('\t');
                case 'u' -> {
                    if (i + 4 > s.length()) throw erro("escape incompleto");
                    sb.append((char) Integer.parseInt(s.substring(i, i + 4), 16));
                    i += 4;
                }
                default -> throw erro("escape inválido");
            }
        }
    }

    private char olhar() {
        if (i >= s.length()) throw erro("o texto acabou no meio do objeto");
        return s.charAt(i);
    }

    private char proximo() {
        char c = olhar();
        i++;
        return c;
    }

    private void esperar(char esperado) {
        if (proximo() != esperado) throw erro("esperava " + esperado);
    }

    private void espacos() {
        while (i < s.length() && Character.isWhitespace(s.charAt(i))) i++;
    }

    private IllegalArgumentException erro(String mensagem) {
        return new IllegalArgumentException(mensagem + " na posição " + i);
    }

    /** Um texto Java como texto JSON, com aspas e os escapes necessários. */
    static String texto(String valor) {
        StringBuilder sb = new StringBuilder("\"");
        for (char c : valor.toCharArray()) {
            switch (c) {
                case '"' -> sb.append("\\\"");
                case '\\' -> sb.append("\\\\");
                case '\n' -> sb.append("\\n");
                case '\t' -> sb.append("\\t");
                default -> {
                    if (c < 0x20) sb.append(String.format("\\u%04x", (int) c));
                    else sb.append(c);
                }
            }
        }
        return sb.append('"').toString();
    }
}
```

Para **escrever** JSON, use sempre `Json.texto(...)` nos textos. Nunca cole um texto do usuário direto entre aspas.

## O que construir

1. O record `Tarefa` com o método `json()`.
2. Um contexto `/tarefas` que roteia pelo caminho e pelo método: `GET /tarefas` lista em ordem de id, `POST /tarefas` cria, `GET /tarefas/{id}` busca.
3. A criação responde `201` com o cabeçalho `Location: /tarefas/1` e a tarefa no corpo.
4. Uma tarefa que não existe, ou um id que nem é número, responde `404`.
5. Troque `TesteDaApi` por um método `pedir(...)` que manda uma requisição, compara o status com o esperado e imprime `ok` ou `ERRO`. Commit: `feat: criar, listar e buscar tarefas`.

> [!IA]
> Peça a uma IA para "devolver a tarefa em JSON sem biblioteca" e é comum vir `String.format("{\"titulo\":\"%s\"}", titulo)`. Com o título `x", "admin": true, "y": "`, a resposta vira um JSON com um campo que ninguém criou: é uma **injeção**, prima da injeção de SQL. Quando pedir ajuda com código que monta texto para outro sistema ler, seja JSON, SQL ou HTML, peça explicitamente o escape, e confira com uma entrada maliciosa.
