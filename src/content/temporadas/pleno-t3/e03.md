Um `Map` associa **chaves** a **valores**: cada chave aparece uma vez e aponta para um valor. É a estrutura por trás de caches, contadores, índices e agrupamentos. Este episódio cobre as três implementações principais e os métodos que o Java 8 acrescentou, `merge`, `compute` e companhia, que a prova adora porque cada um trata `null` de um jeito.

## Os métodos básicos

`Map` não estende `Collection`. Os métodos essenciais:

| Método | O que faz |
|---|---|
| `put(k, v)` | Associa e **devolve o valor anterior**, ou `null` |
| `get(k)` | Devolve o valor, ou `null` se a chave não existe |
| `getOrDefault(k, padrao)` | Devolve o valor, ou o padrão se a chave não existe |
| `containsKey(k)` / `containsValue(v)` | Testam presença |
| `remove(k)` | Remove e devolve o valor |
| `keySet()` / `values()` / `entrySet()` | **Visões** das chaves, dos valores e dos pares |

```java executar
import java.util.Map;
import java.util.TreeMap;

public class Basico {
    public static void main(String[] args) {
        Map<String, Integer> estoque = new TreeMap<>();
        System.out.println(estoque.put("caneta", 10));
        System.out.println(estoque.put("caneta", 7));
        estoque.put("lápis", 3);
        System.out.println(estoque.get("caneta") + " " + estoque.get("borracha") + " " + estoque.getOrDefault("borracha", 0));

        for (Map.Entry<String, Integer> item : estoque.entrySet()) {
            item.setValue(item.getValue() * 2);
        }
        estoque.keySet().remove("lápis");
        System.out.println(estoque);
    }
}
```

```saida
null
10
7 null 0
{caneta=14}
```

As visões estão ligadas ao mapa: `setValue` numa entrada altera o valor guardado, e remover pela `keySet()` remove o par inteiro. `get` devolvendo `null` não prova que a chave não existe, porque o valor pode ser `null`. Para ter certeza, use `containsKey`.

## HashMap, LinkedHashMap e TreeMap

| Implementação | Ordem das chaves | `null` como chave | Custo de `get` e `put` |
|---|---|---|---|
| `HashMap` | Nenhuma garantida | Uma | O(1) em média |
| `LinkedHashMap` | De inserção, ou de acesso | Uma | O(1) em média |
| `TreeMap` | Ordenada | `NullPointerException` | O(log n) |

`Hashtable` é a versão antiga e sincronizada, que não aceita `null` nem como chave nem como valor; não use em código novo. O `TreeMap` implementa `NavigableMap`, com os mesmos métodos de navegação do `TreeSet`, agora para chaves: `firstKey`, `floorKey`, `ceilingEntry`, `headMap`, `tailMap` e `descendingMap`.

```java executar
import java.util.Map;
import java.util.TreeMap;

public class Faixas {
    public static void main(String[] args) {
        TreeMap<Integer, String> faixas = new TreeMap<>(Map.of(0, "infantil", 13, "adolescente", 18, "adulto", 60, "sênior"));
        for (int idade : new int[] {7, 13, 45, 72}) {
            System.out.println(idade + ": " + faixas.floorEntry(idade).getValue());
        }
        System.out.println(faixas.headMap(18) + " " + faixas.firstKey() + " " + faixas.ceilingKey(50));
    }
}
```

```saida
7: infantil
13: adolescente
45: adulto
72: sênior
{0=infantil, 13=adolescente} 0 60
```

`floorEntry` transforma o mapa ordenado numa tabela de faixas: para cada idade, a maior chave que não passa dela.

## Os métodos modernos

O Java 8 acrescentou métodos que fazem em uma chamada o que antes exigia um `get`, um `if` e um `put`:

| Método | Quando age | Se a função devolver `null` |
|---|---|---|
| `putIfAbsent(k, v)` | Chave ausente ou com valor `null` | Não se aplica |
| `computeIfAbsent(k, f)` | Chave ausente ou com valor `null` | Nada é inserido |
| `computeIfPresent(k, f)` | Chave presente com valor não nulo | A chave é **removida** |
| `compute(k, f)` | Sempre; a função recebe `null` se não houver valor | A chave é **removida** |
| `merge(k, v, f)` | Ausente: insere `v`; presente: aplica `f(antigo, v)` | A chave é **removida** |

Os dois usos mais comuns são contar e agrupar:

```java executar
import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.TreeMap;

public class Modernos {
    public static void main(String[] args) {
        Map<String, Integer> contagem = new TreeMap<>();
        for (String palavra : "o rato roeu o rato".split(" ")) {
            contagem.merge(palavra, 1, Integer::sum);
        }
        System.out.println(contagem);

        Map<String, List<String>> porInicial = new TreeMap<>();
        for (String nome : List.of("Ana", "Bia", "Alex", "Caio", "Beto")) {
            porInicial.computeIfAbsent(nome.substring(0, 1), k -> new ArrayList<>()).add(nome);
        }
        System.out.println(porInicial);

        contagem.computeIfPresent("rato", (k, v) -> v * 10);
        contagem.compute("roeu", (k, v) -> v == null ? 0 : v + 100);
        contagem.merge("o", 1, (antigo, novo) -> null);
        contagem.computeIfAbsent("nada", k -> null);
        System.out.println(contagem);
    }
}
```

```saida
{o=2, rato=2, roeu=1}
{A=[Ana, Alex], B=[Bia, Beto], C=[Caio]}
{rato=20, roeu=101}
```

Na última linha, o `merge` cuja função devolve `null` **removeu** "o", e o `computeIfAbsent` cuja função devolve `null` não inseriu "nada". `merge` com `Integer::sum` é o contador clássico: insere 1 na primeira vez e soma nas seguintes. `computeIfAbsent` devolve o valor já existente ou o recém-criado, por isso o `.add(nome)` encadeado funciona nos dois casos.

> [!PROVA]
> Os métodos "se ausente" tratam um valor `null` como ausência: `putIfAbsent` substitui um `null` existente. E toda função de `compute`, `computeIfPresent` ou `merge` que devolve `null` **remove** a chave.

## Map.of, Map.ofEntries e Map.copyOf

`Map.of(k1, v1, k2, v2, ...)` aceita até 10 pares; para mais, use `Map.ofEntries(Map.entry(k, v), ...)`. Os mapas resultantes são imutáveis, rejeitam `null` em chaves e valores e lançam `IllegalArgumentException` com chaves repetidas. A ordem de iteração deles não é garantida e, como você verá no [último episódio](/assistir/pleno-t3-e07), muda de propósito entre execuções.

## Por baixo dos panos

O `HashMap` é um array de compartimentos (*buckets*). Para achar o compartimento de uma chave, ele pega o `hashCode`, mistura os 16 bits altos nos baixos (`h ^ (h >>> 16)`) e usa os bits finais como índice, porque o tamanho do array é sempre potência de 2. Chaves que caem no mesmo compartimento formam uma lista ligada. Quando o mapa passa de 75% de ocupação, o *fator de carga* padrão, o array dobra e as entradas são redistribuídas.

Desde o Java 8, quando um compartimento que já tem 8 entradas recebe mais uma, ele vira uma **árvore rubro-negra**, desde que a tabela tenha pelo menos 64 posições; numa tabela menor, o mapa prefere dobrar de tamanho. Isso protege contra códigos hash ruins ou maliciosos: um atacante que mande milhares de chaves com o mesmo hash degradaria a busca para O(n) numa lista, mas fica em O(log n) na árvore.

O `LinkedHashMap` acrescenta uma lista duplamente ligada passando por todas as entradas. Com o construtor `new LinkedHashMap<>(16, 0.75f, true)`, a lista segue a ordem de **acesso**, e sobrescrever `removeEldestEntry` transforma o mapa num cache LRU, que descarta o item usado há mais tempo:

```java executar
import java.util.LinkedHashMap;
import java.util.Map;

public class CacheLru {
    public static void main(String[] args) {
        Map<String, Integer> cache = new LinkedHashMap<>(16, 0.75f, true) {
            @Override
            protected boolean removeEldestEntry(Map.Entry<String, Integer> maisAntiga) {
                return size() > 3;
            }
        };
        cache.put("a", 1);
        cache.put("b", 2);
        cache.put("c", 3);
        cache.get("a");
        cache.put("d", 4);
        System.out.println(cache);
    }
}
```

```saida
{c=3, a=1, d=4}
```

O `get("a")` levou "a" para o fim da fila, e "b" virou o mais antigo, descartado quando "d" chegou.

## Resumo para a prova

- `put` e `remove` devolvem o valor anterior; `get` devolve `null` se a chave não existe
- `keySet`, `values` e `entrySet` são visões ligadas ao mapa
- `HashMap` sem ordem, `LinkedHashMap` na inserção (ou acesso), `TreeMap` ordenado e sem chave `null`
- "Se ausente" inclui o caso de valor `null`; função que devolve `null` remove a chave
- `Map.of` vai até 10 pares, rejeita `null` e chaves repetidas
- O `HashMap` usa compartimentos, dobra a 75% e transforma listas longas em árvores
