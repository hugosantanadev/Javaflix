A classe `String` tem mais de 60 métodos, e a prova cobra uma dúzia deles em detalhes: onde exatamente o `substring` corta, o que `indexOf` devolve quando não acha, por que `replaceAll(".", "-")` apaga tudo e por que `split` às vezes devolve menos pedaços do que parece. Este episódio passa pelos métodos que caem, agrupados pelo que fazem.

## Procurar e recortar

| Método | Devolve |
|---|---|
| `indexOf(x)` / `lastIndexOf(x)` | a primeira (ou última) posição de `x`, ou **−1** se não existir |
| `indexOf(x, desde)` | a primeira posição a partir de `desde` |
| `substring(inicio)` | do `inicio` até o fim |
| `substring(inicio, fim)` | do `inicio` (incluído) até o `fim` (**excluído**) |
| `contains`, `startsWith`, `endsWith` | `boolean` |

O `fim` excluído é a regra mais importante: `substring(1, 4)` tem 4 − 1 = 3 caracteres. E `x` pode ser um `char` ou uma `String`.

```java executar
String email = "ana.silva@javaflix.com";
int arroba = email.indexOf('@');
System.out.println(arroba);
System.out.println(email.substring(0, arroba));
System.out.println(email.substring(arroba + 1));
System.out.println(email.lastIndexOf('.'));
System.out.println(email.indexOf("xyz"));
System.out.println(email.substring(email.length()).isEmpty());
```

```saida
9
ana.silva
javaflix.com
18
-1
true
```

`substring(length())` é válido e devolve `""`. Já um índice negativo, maior que o tamanho, ou um `inicio` maior que o `fim` lança `StringIndexOutOfBoundsException`.

## Transformar

Todos estes devolvem uma `String` **nova** (a original é [imutável](/assistir/estagiario-t5-e01)), o que permite encadear chamadas:

| Método | Faz |
|---|---|
| `toUpperCase()` / `toLowerCase()` | maiúsculas / minúsculas |
| `trim()` | remove espaços e caracteres de controle (código ≤ 32) das pontas |
| `strip()`, `stripLeading()`, `stripTrailing()` | remove espaços em branco Unicode das pontas (Java 11) |
| `replace(a, b)` | troca **todas** as ocorrências; `a` e `b` são dois `char` ou dois textos |
| `replaceAll(regex, b)` / `replaceFirst(regex, b)` | troca usando uma **expressão regular** |
| `repeat(n)` | repete o texto n vezes (Java 11) |
| `concat(s)` | o mesmo que `+`, mas só aceita `String` |

```java executar
String s = "  Olá, Mundo  ";
System.out.println("[" + s.trim() + "]");
System.out.println(s.strip().toUpperCase().replace('O', '0'));
System.out.println("ab".repeat(3));
System.out.println("banana".replace("an", "AN"));
System.out.println("a.b.c".replaceAll(".", "-"));
System.out.println("a.b.c".replace(".", "-"));
```

```saida
[Olá, Mundo]
0LÁ, MUND0
ababab
bANANa
-----
a-b-c
```

A penúltima linha é a pegadinha: em expressão regular, `.` significa "qualquer caractere", e `replaceAll` trocou os cinco. O `replace` trata o texto literalmente.

## Dividir e juntar

`split(regex)` quebra a `String` em pedaços usando uma **expressão regular** como separador, e descarta as strings vazias **do final**. `String.join` faz o caminho inverso:

```java executar
String csv = "ana,bia,,caio,,";
String[] partes = csv.split(",");
System.out.println(partes.length);
System.out.println(String.join("|", partes));
System.out.println("a.b.c".split(".").length);
System.out.println("a.b.c".split("\\.").length);
```

```saida
4
ana|bia||caio
0
3
```

O vazio do meio (entre `bia` e `caio`) é mantido; os dois do fim somem. E `split(".")` devolve um array vazio: todo caractere casa com o `.`, todos os pedaços são vazios, e todos são descartados. Para dividir por um ponto literal, escape-o: `"\\."` (a barra dupla é porque `\` também precisa de escape dentro do literal Java). Para manter os vazios do fim, use `split(",", -1)`.

## Comparar e ordenar

`compareTo` compara em ordem **lexicográfica** (de dicionário, pelo código de cada caractere): devolve um negativo se a `String` vem antes, zero se são iguais e um positivo se vem depois. O valor exato é a diferença entre os primeiros caracteres diferentes, ou entre os tamanhos, se uma for prefixo da outra:

```java executar
System.out.println("abc".compareTo("abd"));
System.out.println("b".compareTo("a"));
System.out.println("Zebra".compareTo("abacaxi"));
System.out.println("java".compareTo("javaflix"));
System.out.println("JAVA".compareToIgnoreCase("java"));
```

```saida
-1
1
-7
-4
0
```

"Zebra" vem antes de "abacaxi" porque as maiúsculas têm códigos menores que as minúsculas (Z é 90, a é 97). Para ordenar nomes como as pessoas esperam, use `compareToIgnoreCase` ou, para acentos e idiomas, um `java.text.Collator`. Igualdade (`equals` e `==`) tem um episódio só dela, [o último desta temporada](/assistir/estagiario-t5-e05).

## Formatar

`String.format` (e o método de instância `formatted`, do Java 15) monta texto a partir de um modelo com marcadores: `%s` para texto, `%d` para inteiros, `%f` para ponto flutuante, com largura e precisão opcionais:

```java executar
String linha = String.format(Locale.US, "%-6s|%5.2f|%03d", "pão", 3.5, 7);
System.out.println(linha);
System.out.println("Olá, %s! Você tem %d pontos.".formatted("Ana", 120));
```

```saida
pão   | 3.50|007
Olá, Ana! Você tem 120 pontos.
```

`%-6s` alinha à esquerda em 6 posições; `%5.2f` usa 5 posições com 2 casas decimais; `%03d` completa com zeros. O `Locale.US` garante o ponto decimal: sem ele, num computador configurado em português, `%f` usaria vírgula.

> [!VERSAO]
> **Java 21 (1Z0-830 e 1Z0-831).** Ganharam versões novas: `indexOf(ch, inicio, fim)`, que procura só num trecho, e `splitWithDelimiters`, que mantém os separadores no resultado. O `StringBuilder` ganhou `repeat`.

```java executar java21
String s = "banana";
System.out.println(s.indexOf('a', 2, 4));
System.out.println(s.indexOf('a', 4, 5));
```

```saida
3
-1
```

## Por baixo dos panos

Vários métodos de `String` são **intrínsecos** da JVM: o JIT não executa o código Java deles, e sim uma versão em assembly feita à mão para cada processador, que usa instruções vetoriais (SIMD) para comparar 16 ou 32 bytes de uma vez. `indexOf`, `equals` e `compareTo` estão nessa lista. É por isso que buscar um caractere numa `String` grande com `indexOf` costuma ser bem mais rápido que um laço com `charAt`. Já `split` e `replaceAll` compilam uma expressão regular a cada chamada (exceto para separadores simples de um caractere, que têm um caminho rápido), e por isso não convém usá-los dentro de laços quentes.

## Resumo para a prova

- `indexOf` e `lastIndexOf` devolvem −1 quando não acham
- `substring(inicio, fim)`: `inicio` incluído, `fim` excluído; `substring(length())` é `""`
- `replace` é literal e troca todas as ocorrências; `replaceAll` e `split` usam expressão regular
- `"a.b.c".replaceAll(".", "-")` é `"-----"` e `"a.b.c".split(".")` tem tamanho 0
- `split` descarta as strings vazias do final, mas mantém as do meio
- `compareTo`: diferença dos primeiros caracteres diferentes, ou dos tamanhos; maiúsculas vêm antes
- `trim` remove caracteres ≤ 32; `strip` remove espaços Unicode
- `String.format`/`formatted`: `%s`, `%d`, `%f`, com largura e precisão; o separador decimal depende do `Locale`
