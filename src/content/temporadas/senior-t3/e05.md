O [episódio anterior](/assistir/senior-t3-e04) montou e transformou caminhos sem tocar no disco. Agora é hora de agir: criar pastas, ler e gravar arquivos, copiar, mover e apagar. Tudo isso fica na classe **`Files`**, só de métodos estáticos, que recebem um `Path`. Ela substitui, com vantagens, quase todo o uso da antiga `java.io.File`: os métodos lançam exceções que dizem **o que** deu errado, em vez de devolver `false` em silêncio.

## Consultar e criar

| Método | Faz |
|---|---|
| `exists`, `notExists` | Se o caminho existe (ou se com certeza não existe) |
| `isRegularFile`, `isDirectory` | O tipo do que está no caminho |
| `isReadable`, `isWritable`, `isExecutable` | Permissões |
| `size(p)` | Tamanho em bytes |
| `createFile(p)` | Cria um arquivo vazio; `FileAlreadyExistsException` se já existir |
| `createDirectory(p)` | Cria **uma** pasta; a pasta mãe precisa existir |
| `createDirectories(p)` | Cria a pasta e as que faltarem no caminho; não reclama se já existir |
| `createTempFile`, `createTempDirectory` | Cria na pasta temporária do sistema, com nome único |

## Ler e gravar arquivos pequenos

Para arquivos que cabem na memória, `Files` resolve leitura e escrita numa linha. A codificação padrão de todos esses métodos é **UTF-8**, em qualquer versão do Java, e há versões que recebem um `Charset`.

| Leitura | Escrita |
|---|---|
| `readString(p)`: tudo numa `String` (Java 11) | `writeString(p, texto, opções...)` (Java 11) |
| `readAllLines(p)`: uma `List<String>` | `write(p, linhas, opções...)`: uma linha por elemento |
| `readAllBytes(p)`: um `byte[]` | `write(p, bytes, opções...)` |

Sem opções, a escrita **cria** o arquivo se ele não existir e **substitui** o conteúdo se existir. As opções de `StandardOpenOption` mudam isso: `APPEND` acrescenta ao fim, `CREATE_NEW` falha se o arquivo já existir, e `CREATE` com `APPEND` cria ou acrescenta.

```java executar
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardOpenOption;
import java.util.List;

public class LerEscrever {
    public static void main(String[] args) throws IOException {
        Path base = Files.createTempDirectory("javaflix");
        Path pasta = Files.createDirectories(base.resolve("dados/2024"));
        Path notas = pasta.resolve("notas.txt");
        System.out.println(Files.exists(notas) + " " + Files.isDirectory(pasta));

        Files.writeString(notas, "Ana;9\nBruno;7\n");
        Files.writeString(notas, "Carla;8\n", StandardOpenOption.APPEND);
        System.out.println(Files.exists(notas) + " " + Files.isRegularFile(notas) + " " + Files.size(notas) + " bytes");

        List<String> linhas = Files.readAllLines(notas, StandardCharsets.UTF_8);
        System.out.println(linhas.size() + " linhas, a segunda é " + linhas.get(1));
        System.out.print(Files.readString(notas));

        Files.write(notas, List.of("Diego;6"));
        System.out.println(Files.readAllLines(notas));

        Files.delete(notas);
        Files.delete(pasta);
        Files.delete(pasta.getParent());
        Files.delete(base);
        System.out.println(Files.exists(base));
    }
}
```

```saida
false true
true true 22 bytes
3 linhas, a segunda é Bruno;7
Ana;9
Bruno;7
Carla;8
[Diego;6]
false
```

O `createDirectories` criou `dados` e `2024` de uma vez. O `write` sem opções substituiu as três linhas por uma. No fim, as pastas são apagadas de dentro para fora, porque `delete` não apaga pasta com conteúdo.

## Arquivos grandes: streams e leitores

Os métodos acima carregam o arquivo inteiro na memória. Para arquivos grandes, `Files` cria os streams dos episódios anteriores já configurados:

- `Files.lines(p)`: um `Stream<String>` **preguiçoso**, que lê as linhas conforme o pipeline pede. Ele segura o arquivo aberto e precisa ser fechado, num try-with-resources.
- `Files.newBufferedReader(p)` e `Files.newBufferedWriter(p, opções...)`: leitor e escritor bufferizados, em UTF-8.
- `Files.newInputStream(p)` e `Files.newOutputStream(p, opções...)`: streams de bytes.

```java executar
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardOpenOption;
import java.util.stream.Stream;

public class Fluxos {
    public static void main(String[] args) throws IOException {
        Path log = Files.createTempFile("acessos", ".log");
        try (BufferedWriter w = Files.newBufferedWriter(log)) {
            w.write("200 /inicio\n404 /sumiu\n200 /aulas\n500 /erro\n");
        }
        try (BufferedWriter w = Files.newBufferedWriter(log, StandardOpenOption.APPEND)) {
            w.write("404 /velha\n");
        }
        try (Stream<String> linhas = Files.lines(log)) {
            System.out.println(linhas.filter(l -> l.startsWith("404")).map(l -> l.substring(4)).toList());
        }
        try (BufferedReader r = Files.newBufferedReader(log)) {
            System.out.println(r.readLine() + " | " + r.lines().count() + " restantes");
        }
        try {
            Files.createFile(log);
        } catch (IOException e) {
            System.out.println(e.getClass().getSimpleName());
        }
        Files.delete(log);
    }
}
```

```saida
[/sumiu, /velha]
200 /inicio | 4 restantes
FileAlreadyExistsException
```

## Copiar, mover e apagar

| Método | Faz | Falha com |
|---|---|---|
| `copy(origem, destino, opções...)` | Copia um arquivo | `FileAlreadyExistsException` se o destino existir |
| `move(origem, destino, opções...)` | Move ou renomeia | `FileAlreadyExistsException` se o destino existir |
| `delete(p)` | Apaga | `NoSuchFileException` se não existir; `DirectoryNotEmptyException` se for pasta com conteúdo |
| `deleteIfExists(p)` | Apaga se existir | `DirectoryNotEmptyException`; devolve `boolean` |
| `mismatch(a, b)` | Compara conteúdos (Java 12) | Devolve -1 se iguais, ou a posição do primeiro byte diferente |

As opções de `StandardCopyOption` são `REPLACE_EXISTING`, para sobrescrever o destino, `COPY_ATTRIBUTES`, para manter datas e permissões, e `ATOMIC_MOVE`, para que o `move` aconteça de uma vez só ou não aconteça. Copiar uma **pasta** cria só a pasta vazia no destino, sem o conteúdo; para copiar uma árvore, é preciso percorrê-la, assunto do [próximo episódio](/assistir/senior-t3-e06). Já `move` numa pasta, dentro do mesmo disco, leva tudo junto, porque é só uma renomeação.

```java executar
import java.io.IOException;
import java.nio.file.DirectoryNotEmptyException;
import java.nio.file.FileAlreadyExistsException;
import java.nio.file.Files;
import java.nio.file.NoSuchFileException;
import java.nio.file.Path;
import java.nio.file.StandardCopyOption;

public class CopiarMover {
    public static void main(String[] args) throws IOException {
        Path base = Files.createTempDirectory("javaflix");
        Path original = Files.writeString(base.resolve("original.txt"), "versão 1");
        Path copia = base.resolve("copia.txt");

        Files.copy(original, copia);
        Files.writeString(original, "versão 2");
        try {
            Files.copy(original, copia);
        } catch (FileAlreadyExistsException e) {
            System.out.println("já existe: " + Files.readString(copia));
        }
        Files.copy(original, copia, StandardCopyOption.REPLACE_EXISTING);
        System.out.println("substituída: " + Files.readString(copia) + ", diferença em " + Files.mismatch(original, copia));

        Path pasta = Files.createDirectory(base.resolve("arquivo-morto"));
        Path movido = Files.move(copia, pasta.resolve("antiga.txt"));
        System.out.println(Files.exists(copia) + " " + movido.getFileName() + " " + Files.readString(movido));

        try {
            Files.delete(pasta);
        } catch (DirectoryNotEmptyException e) {
            System.out.println("pasta não está vazia");
        }
        try {
            Files.delete(base.resolve("fantasma.txt"));
        } catch (NoSuchFileException e) {
            System.out.println("não existe: " + Path.of(e.getFile()).getFileName());
        }
        System.out.println(Files.deleteIfExists(movido) + " " + Files.deleteIfExists(movido));

        Files.delete(pasta);
        Files.delete(original);
        Files.delete(base);
    }
}
```

```saida
já existe: versão 1
substituída: versão 2, diferença em -1
false antiga.txt versão 2
pasta não está vazia
não existe: fantasma.txt
true false
```

Todas essas exceções, `FileAlreadyExistsException`, `NoSuchFileException` e `DirectoryNotEmptyException`, são subclasses de `FileSystemException`, que é uma `IOException`, e guardam o caminho envolvido em `getFile()`.

> [!PROVA]
> `createDirectory` exige a pasta mãe; `createDirectories` cria tudo. `copy` e `move` falham se o destino existir, salvo com `REPLACE_EXISTING`. `delete` lança `NoSuchFileException` ou `DirectoryNotEmptyException`; `deleteIfExists` devolve `boolean`. Copiar uma pasta não copia o conteúdo. `Files.lines` precisa ser fechado. `mismatch` devolve -1 para arquivos iguais. Os métodos de `Files` usam UTF-8 por padrão.

## Por baixo dos panos

`Files` não faz quase nada sozinha: cada método pega o `FileSystemProvider` do caminho, com `path.getFileSystem().provider()`, e delega a ele. É por isso que a mesma chamada funciona no disco local, num ZIP ou num sistema de arquivos em memória. E cada provedor pode usar os recursos do seu sistema: entre dois arquivos locais, `Files.copy` pode recorrer a chamadas que copiam os dados dentro do próprio núcleo, sem passar os bytes pela memória do programa.

O `move` com `ATOMIC_MOVE` vira a chamada de sistema `rename`, que o sistema de arquivos garante ser atômica: quem olhar a pasta verá o arquivo antigo ou o novo, nunca um pela metade. É o truque para gravar um arquivo com segurança: escreve-se num arquivo temporário na mesma pasta e, no fim, move-se atomicamente por cima do original. Se o programa cair no meio da escrita, o original continua intacto. Entre discos diferentes, o `rename` não funciona, e um `move` comum vira cópia seguida de exclusão; com `ATOMIC_MOVE`, lança `AtomicMoveNotSupportedException`.

## Resumo para a prova

- Consultas: `exists`, `isDirectory`, `isRegularFile`, `size`; criação: `createFile`, `createDirectory`, `createDirectories`
- Pequenos: `readString`, `readAllLines`, `readAllBytes`, `writeString`, `write`; grandes: `lines`, `newBufferedReader`, `newBufferedWriter`
- Escrita padrão cria ou substitui; `APPEND` acrescenta; `CREATE_NEW` exige arquivo novo
- `copy`/`move` com `REPLACE_EXISTING` para sobrescrever; copiar pasta não leva o conteúdo
- `delete` lança `NoSuchFileException` e `DirectoryNotEmptyException`; `deleteIfExists` devolve `boolean`
- `Files.lines` em try-with-resources; `mismatch` devolve -1 quando os arquivos são iguais
