Um laço dentro de outro é como os ponteiros de um relógio: a cada volta do externo, o interno dá a volta completa. É assim que se percorre uma matriz, se compara cada elemento com todos os outros, se desenha um padrão na tela. Este episódio ensina a contar quantas vezes o corpo interno executa, inclusive quando o limite do laço interno depende do externo, que é o tipo de conta que a prova pede.

## A volta completa do interno

Para cada valor do laço externo, o interno começa do zero e vai até o fim. Uma tabuada mostra o padrão:

```java executar
for (int i = 1; i <= 3; i++) {
    StringJoiner linha = new StringJoiner(" "); //> Criada dentro do externo: começa vazia a cada linha.
    for (int j = 1; j <= 3; j++) {
        linha.add(String.valueOf(i * j)); //> O j vai de 1 a 3 inteiro antes de o i mudar.
    }
    System.out.println(linha);
}
```

```saida
1 2 3
2 4 6
3 6 9
```

A variável `linha` é criada **dentro** do laço externo, então começa vazia a cada volta. Se fosse declarada antes dele, acumularia as três linhas numa só.

> [!ERRO]
> Declarar antes do laço externo uma variável que deveria recomeçar a cada linha: um contador, uma soma parcial, um texto. `int somaDaLinha = 0;` fora dos dois laços faz a segunda linha somar por cima da primeira. Declare essas variáveis dentro do laço externo, logo antes do interno, ou zere-as ali.

> [!CONVERSA]
> **Laço externo:** Eu sou o ponteiro das horas. Ando um passo e espero.
>
> **Laço interno:** E eu sou o dos minutos: a cada passo seu, dou a volta inteira no mostrador.
>
> **Laço externo:** Então, se eu dou 4 passos e você tem 5 posições, o corpo roda 20 vezes.
>
> **Laço interno:** Desde que o meu limite seja fixo. Se ele depender de você, como `j < i`, eu dou voltas de tamanhos diferentes, e aí a conta vira uma soma.
>
> **Laço externo:** E quem esquece de zerar a soma dentro de mim vê a segunda linha somada com a primeira.

## Contando as execuções

Com limites fixos, o total é o produto: um laço de 4 voltas com outro de 5 dentro executa o corpo 4 × 5 = 20 vezes. Quando o limite interno depende do externo, o total é uma **soma**:

```java executar
int a = 0, b = 0, c = 0;
for (int i = 0; i < 4; i++)
    for (int j = 0; j < 5; j++)
        a++; //> 5 voltas para cada um dos 4 valores de i.
for (int i = 0; i < 4; i++)
    for (int j = 0; j < i; j++)
        b++; //> 0, 1, 2 e 3 voltas: o limite cresce com o i.
for (int i = 1; i <= 16; i *= 2)
    for (int j = 0; j < i; j++)
        c++; //> 1, 2, 4, 8 e 16 voltas: o i dobra.
System.out.println(a + " " + b + " " + c);
```

```saida
20 6 31
```

| Laço | Voltas do interno | Total |
|---|---|---|
| `a` | 5 em cada uma das 4 voltas | 4 × 5 = 20 |
| `b` | 0, 1, 2, 3 | 0 + 1 + 2 + 3 = 6 |
| `c` | 1, 2, 4, 8, 16 | 31 |

![Duas grades de linhas i por colunas j: na da esquerda, todas as 20 casas estão preenchidas; na da direita, só as 6 casas abaixo da diagonal, com 0, 1, 2 e 3 por linha](/figuras/contando-lacos-aninhados.svg "Cada casa preenchida é uma execução do corpo. Contar por linha e somar é o método que funciona em qualquer caso.")

O padrão do `b` é a soma de Gauss que você viu no episódio de [Big-O](/assistir/aprendiz-t3-e05): com n voltas externas, 0 + 1 + ... + (n − 1) = n(n − 1)/2. É o número de **pares** de elementos distintos de um conjunto, e aparece sempre que o laço interno começa em `j = i + 1` ou vai até `j < i`. O `c` é uma soma geométrica: 1 + 2 + 4 + 8 + 16 = 2⁵ − 1.

> [!MATEMATICA]
> Por que 0 + 1 + ... + (n − 1) dá n(n − 1)/2? Escreva a soma duas vezes, uma de trás para a frente, e some coluna a coluna: 0 + (n − 1), 1 + (n − 2), e assim por diante. Cada coluna dá n − 1, e são n colunas, então o dobro da soma é n(n − 1). Na figura, é o mesmo que dizer que o triângulo verde é quase metade do quadrado n × n: tira-se a diagonal (n casas) e divide-se o resto por 2, (n² − n)/2. Com n = 4, (16 − 4)/2 = 6.

> [!LAPIS]
> Quantas vezes o `n++` executa?
>
> ```java
> int n = 0;
> for (int i = 1; i <= 4; i++)
>     for (int j = 1; j <= 4; j += i)
>         n++;
> ```
>
> **Resposta:** `9`. Escreva as voltas do interno para cada i. Com i = 1, o j passa por 1, 2, 3 e 4: 4 voltas. Com i = 2, por 1 e 3: 2. Com i = 3, por 1 e 4: 2. Com i = 4, só pelo 1: 1. Somando, 4 + 2 + 2 + 1 = 9.

> [!PROVA]
> Para contar execuções sem errar: escreva o número de voltas do laço interno para cada valor do externo, numa linha, e some. Atenção aos limites (`<` ou `<=`), ao valor inicial do interno (0, 1 ou `i`) e ao passo de cada laço.

## Padrões na tela

Desenhar com laços aninhados é um bom exercício de contagem: o externo controla as linhas, e o interno, o que vai em cada uma.

```java executar
for (int i = 1; i <= 4; i++) {
    for (int j = 1; j <= i; j++) { //> Na linha i, i asteriscos.
        System.out.print("*");
    }
    System.out.println(); //> Fora do interno: fecha a linha.
}
```

```saida
*
**
***
****
```

O `println()` sem argumento, fora do laço interno e dentro do externo, encerra cada linha. Agora monte você um padrão: arrume as linhas para imprimir a escada de números abaixo.

```imas executar
public class Escada {
    public static void main(String[] args) {
        for (int i = 1; i <= 3; i++) {
            for (int j = 1; j <= i; j++) {
                System.out.print(j);
            }
            System.out.println();
        }
    }
}
```

```saida
1
12
123
```

## Matrizes

Uma matriz em Java é um [array de arrays](/assistir/estagiario-t6-e02): `m[i]` é a linha i, e `m[i][j]` é o elemento da coluna j dessa linha. Percorrê-la é o uso mais comum de laços aninhados, e a relação entre `i` e `j` identifica as regiões da matriz:

```java executar
int[][] m = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
int diagonal = 0, acima = 0;
for (int i = 0; i < m.length; i++) {
    for (int j = 0; j < m[i].length; j++) { //> m[i].length: cada linha pode ter seu tamanho.
        if (i == j) {
            diagonal += m[i][j];
        } else if (j > i) {
            acima += m[i][j];
        }
    }
}
System.out.println(diagonal + " " + acima);
```

```saida
15 11
```

A diagonal principal tem `i == j` (1, 5 e 9); acima dela, `j > i` (2, 3 e 6). A diagonal secundária seria `i + j == n − 1`.

## O custo: O(n²)

Dois laços aninhados sobre os mesmos n dados executam da ordem de n² vezes. Com 1.000 elementos, um milhão de operações; com um milhão, um trilhão, o que leva horas. Quando o laço interno só procura algo, como "existe um par que soma 10?", trocar a busca interna por um `HashSet` costuma reduzir o total para O(n), como você viu no episódio de [Big-O](/assistir/aprendiz-t3-e05).

> [!PENSE]
> Somar uma matriz linha por linha ou coluna por coluna faz exatamente o mesmo número de somas. Será que as duas ordens levam o mesmo tempo?

> [!ANTES]
> Até meados dos anos 1980, buscar um número na memória custava mais ou menos o mesmo que uma operação do processador, e a ordem dos laços quase não importava. Desde então, os processadores ficaram muito mais rápidos que a memória, e os caches surgiram para esconder essa diferença. Foi aí que a ordem de percorrer uma matriz passou a pesar no tempo.

## Por baixo dos panos

A ordem dos laços sobre uma matriz muda o desempenho, mesmo com o mesmo número de operações. Cada linha de um `int[][]` é um array contíguo na memória, e o processador carrega a memória para o cache em blocos de 64 bytes (16 `int` de uma vez), como você viu na [hierarquia de memória](/assistir/aprendiz-t1-e04). Percorrer **linha por linha** (o `i` por fora e o `j` por dentro) usa todos os números de cada bloco carregado. Percorrer **coluna por coluna** (o `j` por fora) pula de linha em linha a cada acesso, carrega um bloco novo a cada número e desperdiça os outros 15. Em matrizes grandes, a diferença pode ser de várias vezes, só por trocar a ordem dos dois `for`.

> [!DESEMPENHO]
> Num laço aninhado, cada comando do corpo interno roda n × m vezes. Tire de lá tudo que não depende do `j`: um cálculo que só usa o `i`, como `m[i].length` guardado numa variável ou um `i * largura`, pode ir para o laço externo. E percorra matrizes com o índice da linha por fora.

> [!IA]
> A IA escreve laços aninhados com facilidade, mas raramente avisa quando eles ficam O(n²) sobre dados grandes. Ao pedir uma busca de pares ou de duplicados, pergunte a complexidade e se existe uma versão com `HashSet`. E confira as contagens que ela der rodando o código com contadores, como no exemplo do `a`, `b` e `c`.

## Na IDE

- **Ver as voltas.** Ponha um breakpoint dentro do laço interno e use **F9** (Resume) para parar a cada execução: o painel de variáveis mostra `i` e `j` mudando, como o ponteiro dos minutos.
- **Breakpoint condicional.** Clique com o botão direito no breakpoint e escreva uma condição, como `i == 2 && j == 0`, para parar só na volta que interessa.
- **Gerar o laço.** `fori` + **Tab** cria um `for` com índice; dentro dele, outro `fori` cria o interno e a IDE escolhe `j` sozinha.

## Resumo para a prova

- O laço interno dá a volta completa a cada volta do externo
- Limites fixos: total = produto; limite interno dependente do externo: total = soma das voltas
- `j < i` ou `j` de `i + 1` até n: n(n − 1)/2 execuções
- Variáveis que precisam recomeçar a cada linha são declaradas dentro do laço externo
- Na matriz, `i == j` é a diagonal principal; `j > i` fica acima dela
- Dois laços aninhados sobre n elementos custam O(n²)
- Percorrer matrizes linha por linha aproveita o cache
