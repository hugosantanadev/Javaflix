`break` e `continue` mudam o fluxo de um laço no meio de uma volta. Sozinhos, são simples; com laços aninhados e **rótulos**, viram as questões de saída mais trabalhosas da prova. Este episódio mostra o que cada um faz, como os rótulos escolhem o laço afetado, e onde cada comando é permitido.

## `break` e `continue`

| Comando | Efeito |
|---|---|
| `break` | sai do laço (ou do `switch`) mais interno, imediatamente |
| `continue` | pula o resto da volta atual e vai para a próxima |

No `continue`, "ir para a próxima volta" significa: no `while` e no `do-while`, testar a condição de novo; no `for`, executar a **atualização** e depois testar:

```java executar
for (int i = 1; i <= 6; i++) {
    if (i == 5) {
        break;
    }
    if (i % 2 == 0) {
        continue;
    }
    System.out.println(i);
}
```

```saida
1
3
```

Os pares são pulados pelo `continue`, e o laço acaba no 5 pelo `break`, antes de imprimir o 5. O `i++` do cabeçalho roda normalmente depois de cada `continue`.

> [!ATENCAO]
> Num `while`, o `continue` pula também tudo que estiver no fim do corpo, inclusive a atualização da variável, se ela estiver lá. `while (i < 5) { if (i == 2) continue; i++; }` vira um laço infinito quando `i` chega a 2. No `for`, a atualização fica no cabeçalho e não é pulada.

## Rótulos

Com laços aninhados, `break` e `continue` afetam só o laço mais interno. Para afetar um laço externo, dê um **rótulo** a ele (um nome seguido de dois-pontos) e use o nome no comando:

```java executar
externo:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (j == 2) {
            continue externo;
        }
        if (i == 3) {
            break externo;
        }
        System.out.println(i + "," + j);
    }
}
System.out.println("fim");
```

```saida
1,1
2,1
fim
```

Para i = 1 e i = 2, o laço interno imprime o j = 1 e, no j = 2, o `continue externo` abandona o laço interno e vai para a próxima volta do **externo**. Para i = 3, o `break externo` encerra os dois laços de uma vez.

O uso mais comum do rótulo é sair de dois laços quando se acha o que se procura:

```java executar
int[][] grade = {{4, 7, 1}, {9, 3, 8}, {2, 6, 5}};
int alvoLinha = -1, alvoColuna = -1;
busca:
for (int l = 0; l < grade.length; l++) {
    for (int c = 0; c < grade[l].length; c++) {
        if (grade[l][c] == 3) {
            alvoLinha = l;
            alvoColuna = c;
            break busca;
        }
    }
}
System.out.println(alvoLinha + " " + alvoColuna);
```

```saida
1 1
```

Sem o rótulo, o `break` sairia só do laço interno, e o externo continuaria procurando nas linhas seguintes.

## Onde cada um é permitido

| Comando | Permitido em |
|---|---|
| `break` sem rótulo | dentro de laço ou `switch` |
| `continue` (com ou sem rótulo) | só dentro de laço |
| `break rótulo` | dentro de qualquer comando rotulado, até de um bloco `{ }` ou de um `if` |

O rótulo de um `continue` precisa marcar um **laço**; o de um `break` pode marcar qualquer comando. Usar `continue` fora de laço, ou com o rótulo de um bloco comum, não compila:

```java nao-compila
int x = 1;
if (x > 0) {
    continue;
}
```

```java executar
bloco: {
    System.out.println("antes");
    if (true) {
        break bloco;
    }
    System.out.println("nunca");
}
System.out.println("depois");
```

```saida
antes
depois
```

`break bloco` funciona como um "sair deste bloco", um uso raro, mas que aparece em prova. O `if (true)` está ali porque um `break` direto deixaria o `println("nunca")` [inalcançável](/assistir/estagiario-t3-e04), o que não compila.

> [!PROVA]
> Um rótulo só vale para o comando que ele marca, e precisa estar **em volta** do `break` ou do `continue`: não dá para pular para um rótulo de um laço que já terminou ou que está em outro lugar. Rótulos não são `goto` (que, aliás, é palavra reservada em Java, mas não faz nada). E um `break` dentro de um `switch` que está dentro de um laço sai só do `switch`.

## Por baixo dos panos

Para o bytecode, `break` e `continue` são o que sempre foram: um `goto`. O `break` salta para a primeira instrução depois do laço; o `continue`, para o ponto da atualização (no `for`) ou do teste (no `while`). O rótulo só diz ao `javac` qual laço usar para calcular o endereço do salto. Por isso essa liberdade tem limites: o Java só permite saltar "para fora" de comandos que envolvem o `break`, nunca para dentro de outro bloco, e é isso que mantém o fluxo analisável pelas regras de [código inalcançável e atribuição definida](/assistir/estagiario-t3-e04).

## Resumo para a prova

- `break` sai do laço ou `switch` mais interno; `continue` vai para a próxima volta do laço mais interno
- No `for`, o `continue` executa a atualização antes do teste; no `while`, pula o que houver no fim do corpo
- `break rótulo` e `continue rótulo` afetam o comando rotulado, mesmo que seja externo
- `continue` só existe dentro de laço, e o seu rótulo precisa ser de um laço
- `break rótulo` pode sair de qualquer bloco rotulado
- `break` dentro de `switch` dentro de laço sai só do `switch`
