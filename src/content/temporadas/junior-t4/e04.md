Naipes de baralho, dias da semana, status de um pedido: muitos valores formam um conjunto **fixo e pequeno**. Antes do Java 5, eles viravam constantes `int` (`static final int COPAS = 0;`), e nada impedia alguém de passar 42 onde se esperava um naipe. O **enum** resolve isso: um tipo cujos únicos valores possíveis são os que você listou, verificado pelo compilador.

## Declarar e usar

```java executar
enum Naipe {
    COPAS, ESPADAS, OUROS, PAUS
}

Naipe n = Naipe.OUROS;
System.out.println(n + " " + n.name() + " " + n.ordinal());
System.out.println(Naipe.values().length + " " + Naipe.valueOf("PAUS").ordinal());
for (Naipe x : Naipe.values()) {
    System.out.print(x.ordinal() + ":" + x + " ");
}
System.out.println();
```

```saida
OUROS OUROS 2
4 3
0:COPAS 1:ESPADAS 2:OUROS 3:PAUS
```

Cada constante é um **objeto** do tipo `Naipe`, criado uma única vez, quando a classe é carregada. Os métodos que todo enum ganha:

| Método | Devolve |
|---|---|
| `values()` | um array com todas as constantes, na ordem de declaração |
| `valueOf(String)` | a constante com aquele nome exato |
| `name()` | o nome da constante, como foi escrito |
| `toString()` | o nome, a menos que seja sobrescrito |
| `ordinal()` | a posição na declaração, **começando em 0** |
| `compareTo(outro)` | a comparação pela ordem de declaração |

O `valueOf` diferencia maiúsculas e lança `IllegalArgumentException` se não encontrar o nome:

```java executar
enum Status { ATIVO, INATIVO }

try {
    Status.valueOf("ativo");
} catch (IllegalArgumentException e) {
    System.out.println("IllegalArgumentException");
}
System.out.println(Status.valueOf("ATIVO") == Status.ATIVO);
```

```saida
IllegalArgumentException
true
```

Como cada constante existe uma vez só, comparar enums com `==` é seguro e recomendado. E ninguém cria constantes novas: o construtor de um enum é sempre `private`, e `new` não compila.

```java nao-compila
enum Tamanho { P, M, G }

Tamanho t = new Tamanho();
```

## Enums no `switch`

Enums combinam com `switch`. Nos `case`, as constantes aparecem **sem o nome do tipo**, porque o compilador já sabe qual é o enum. E um `switch` *expressão* que cobre todas as constantes não precisa de `default`, como você viu no [episódio de switch](/assistir/estagiario-t3-e03):

```java executar
enum Semaforo { VERDE, AMARELO, VERMELHO }

Semaforo s = Semaforo.AMARELO;
switch (s) {
    case VERDE:
        System.out.println("siga");
        break;
    case AMARELO:
        System.out.println("atenção");
        break;
    default:
        System.out.println("pare");
}
String acao = switch (s) {
    case VERDE -> "acelera";
    case AMARELO -> "freia";
    case VERMELHO -> "espera";
};
System.out.println(acao);
```

```saida
atenção
freia
```

Até o Java 17, escrever o nome qualificado no `case` não compila:

```java nao-compila
enum Semaforo { VERDE, AMARELO, VERMELHO }

Semaforo s = Semaforo.VERDE;
switch (s) {
    case Semaforo.VERDE:
        System.out.println("siga");
        break;
    default:
        System.out.println("pare");
}
```

> [!VERSAO]
> O Java 21, junto com o pattern matching no `switch` (JEP 441), passou a aceitar o nome qualificado, como `case Semaforo.VERDE`. Na prova 1Z0-829 (Java 17), ele é erro de compilação; nas 1Z0-830 e 831, compila.

```java compila java21
enum Semaforo { VERDE, AMARELO, VERMELHO }

class Teste {
    String ler(Semaforo s) {
        switch (s) {
            case Semaforo.VERDE:
                return "siga";
            default:
                return "pare";
        }
    }
}
```

## Comparação e coleções próprias

`compareTo` segue a ordem de declaração: devolve a diferença entre os `ordinal()`. Para guardar dados por constante, a biblioteca tem `EnumMap` e `EnumSet`, que ficam em ordem de declaração e são muito mais rápidos que as versões genéricas:

```java executar
enum Prioridade { BAIXA, MEDIA, ALTA }

Prioridade a = Prioridade.ALTA;
Prioridade b = Prioridade.valueOf("BAIXA");
System.out.println(a.compareTo(b) + " " + (a == Prioridade.ALTA) + " " + a.equals(b));
Map<Prioridade, Integer> contagem = new EnumMap<>(Prioridade.class);
contagem.put(Prioridade.ALTA, 2);
contagem.put(Prioridade.BAIXA, 5);
System.out.println(contagem);
```

```saida
2 true false
{BAIXA=5, ALTA=2}
```

Cuidado com o `ordinal()` como dado: se alguém inserir uma constante no meio da lista, todos os números mudam. Guardar o `ordinal()` num banco de dados é um erro clássico; guarde o `name()`.

> [!PROVA]
> As pegadinhas de enum: `ordinal()` começa em 0; `valueOf` diferencia maiúsculas e lança `IllegalArgumentException`; `new` num enum não compila; `case` com nome qualificado só compila a partir do Java 21; e um `switch` expressão com enum precisa cobrir todas as constantes ou ter `default`.

## Por baixo dos panos

Um enum é açúcar para uma classe. O `javac` transforma `enum Naipe { COPAS, ... }` em algo como `final class Naipe extends java.lang.Enum<Naipe>`, com um campo `public static final Naipe COPAS` para cada constante e um array privado `$VALUES` com todas. O bloco `static` da classe cria os objetos, passando o nome e a posição ao construtor de `Enum`. Por isso enums não podem estender outra classe: já estendem `Enum`.

O `values()` devolve uma **cópia** desse array a cada chamada, para que ninguém consiga alterar a lista de constantes:

```java executar
enum Cor { VERMELHO, VERDE }

Cor[] copia = Cor.values();
copia[0] = Cor.VERDE;
System.out.println(Cor.values()[0] + " " + (Cor.values() == Cor.values()));
```

```saida
VERMELHO false
```

O `EnumSet` aproveita os ordinais para guardar o conjunto como bits de um `long`: "contém ALTA?" vira testar um bit, como nas [permissões com operadores bit a bit](/assistir/estagiario-t2-e05).

## Resumo para a prova

- Enum é um tipo com um conjunto fixo de constantes, cada uma um objeto único
- `values()`, `valueOf(String)`, `name()`, `ordinal()` e `compareTo` vêm de graça
- `ordinal()` começa em 0; `compareTo` segue a ordem de declaração
- `valueOf` com nome inexistente lança `IllegalArgumentException`
- Comparar com `==` é seguro; `new` num enum não compila
- No `case`, o nome sem o tipo; qualificado só a partir do Java 21
- `switch` expressão cobrindo todas as constantes dispensa `default`
- Enums estendem `java.lang.Enum` e não podem estender outra classe
